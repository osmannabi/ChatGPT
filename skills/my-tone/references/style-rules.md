## A. ASD-STE100 Simplified Technical English

STE was made for aerospace maintenance manuals so that non-native readers understand text the
first time. The same rules make client mail easy to read on a phone.

### Writing rules (the parts that apply to email and posts)

| Rule | What it means here |
|---|---|
| Short sentences | Instructions: 20 words max. Descriptions: 25 words max. |
| One topic per sentence | Do not join two ideas with "and" or a comma. |
| One topic per paragraph | Six sentences max per paragraph. Mehmet usually uses one to three. |
| Active voice | Name who does the action. |
| Imperative for instructions | Start the sentence with the verb. |
| Approved words, one meaning each | Use the simple common word. Do not use a word in two senses in one text. |
| Keep articles | Write "the file," not "file." |
| Simple verb tenses | Prefer simple present, simple past, simple future. Avoid "would have been being." |
| No long noun clusters | Max three nouns in a row. "the label artwork files," not "the print-ready label artwork dieline source files." |
| Lists for steps | Use a numbered list for steps in order. Use bullets for items. |
| Warnings first | Put the condition or risk before the action. |

### Word swaps

| Do not use | Use |
|---|---|
| utilize | use |
| commence, initiate | start |
| terminate | stop, end |
| facilitate | help, make easier |
| approximately | about |
| in order to | to |
| prior to | before |
| subsequent to | after |
| ensure | make sure |
| a number of | some, several |
| at this point in time | now |
| due to the fact that | because |
| endeavor | try |
| obtain | get |
| sufficient | enough |
| require | need |
| additional | more, extra |
| regarding | about |

## B. Google developer style guide: voice and tone

### Aim for
- Conversational, friendly, respectful. Like a knowledgeable friend who understands what the reader needs.
- Second person: "you."
- Contractions: "you'll," "we're," "can't."
- Active voice, present tense where possible.
- Clear before clever. Plain before precise jargon, unless the reader uses that jargon (render, aspect ratio, packshot are fine with clients in the trade).
- Global audience: write so a non-native reader and a translation tool both understand it.

### Avoid
- Words that suggest the task is trivial: "simply," "just," "easy," "easily," "obviously," "of course," "it's that simple."
- Buzzwords and marketing filler: "leverage," "synergy," "cutting-edge," "world-class," "seamless," "robust," "game-changer," "unlock."
- Idioms and slang that do not translate: "hit the ground running," "ballpark," "touch base," "circle back."
- Overly casual or cute writing, pop-culture references, jokes at anyone's expense.
- "Please note that," "It should be noted," "Note that" as filler.
- Exclamation marks (Mehmet's "Hi!" is the only exception).
- Placeholder phrases: "and so on," "etc." when the list can be finished or cut.
- Being too familiar or too formal. Mehmet sits in the middle: polite, direct, warm.

> The files are on Frame.io. You can download all versions there.

## C. Apple Style Guide

### Principles
- **Clear:** one idea at a time, in the order the reader needs it.
- **Simple:** the shortest common word that is correct. Cut every word that adds nothing.
- **Direct:** say what happens and what the reader does. Put the key fact first.
- **Friendly, not familiar:** warm and helpful, never chummy or slangy.
- **Consistent:** one term for one thing. If it is a "render" in line one, it is not an "image," "visual" and "shot" later in the same email.
- **Inclusive and global:** gender-neutral language, no culture-specific references, no idioms.
- **Numbers:** numerals for 10 and above and for all measurements, prices and versions (5 renders, v4, 1920 × 1080, $750).
- **Lists:** parallel structure. Each bullet starts the same way (all verbs, or all nouns).
- **Headings and labels:** short, sentence-style capitalization ("What you'll receive").

### Before and after

> Our team of highly experienced, world-class 3D artists will leverage cutting-edge workflows to
> deliver stunning, best-in-class visuals for your exciting new product line.

> We'll model all 5 varieties in 3D and render each one on white and transparent backgrounds.

## D. Quick test

Read the text out loud once. If you run out of breath in a sentence, split it. If a word sounds
like a brochure, replace it with the word Mehmet would say to a client on a video call.
